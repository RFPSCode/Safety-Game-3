# 桃園市龍山國小之校園安全時光機 Episode 3

依真實事件改編的 3D 校園安全教育遊戲。學生在悠悅樓前的中庭小廣場走到指定地點，進入第一人稱情境。一開始，小惡魔會驅使學生犯錯，學生會看到後果。接著小天使用光束擊退小惡魔，讓時光倒轉，再讓學生自己做出選擇。

情境依真實事件改編，人物為虛構。

## 放上 GitHub Pages

1. 在 GitHub 建立一個新的 repository（例如 `safety-game-3`），設為 Public。
2. 把這個資料夾裡的**所有檔案和資料夾**上傳到 repository 的最上層。`index.html` 要放在最上層。
   - 網頁上傳一次最多 100 個檔案，這個專案不到 20 個，一次就能傳完。
   - `.nojekyll` 是隱藏檔，請一起上傳；沒傳到也不影響遊戲。
3. 到 Settings → Pages，Source 選「Deploy from a branch」，Branch 選 `main`，資料夾選 `/ (root)`，按 Save。
4. 等一兩分鐘，網址會是 `https://你的帳號.github.io/safety-game-3/`。

遊戲需要網路，因為 3D 引擎（three.js、three-vrm）和字型都從 CDN 載入。

**不能直接雙擊 `index.html` 開啟**，因為瀏覽器不允許網頁從本機讀取模型檔。要在自己電腦上試玩，可以在這個資料夾執行 `python -m http.server`，再打開 `http://localhost:8000`。

## 第三集內容

- 任務地點：**悠悅樓平台**，案例是「互推比力氣」，依真實新聞事件改編。故事走向如下：
  1. 小美邀你像相撲一樣手掌互推。小惡魔驅使你突然用力，小美往後倒，後腦撞地。
  2. 小美說不痛、不要告訴老師。三天後，她在病房裡，顱內出血、緊急開刀，右眼半盲。
  3. 小天使出現，發出光束擊退小惡魔。時光倒轉，剛才的動作會倒著回放。
  4. 你自己選擇怎麼回答。選對的話，改玩猜拳，得到「安全遊戲徽章」。選錯的話悲劇重演，遊戲結束。
- 沿用第二集的系統：第一人稱、漫畫分鏡特寫視窗（含慢動作）、小天使光束擊退小惡魔、時光倒轉動作回放、救護車子畫面、成功與失敗結算畫面。
- 第三關地點：**一樓教室走廊**，案例是「走廊競速推人」，依真實法院判決改編。故事走向如下：
  1. 小凱邀你在走廊比賽跑到轉角。快輸的時候，小惡魔驅使你伸手推小凱的背，小凱往前撲倒、頭撞到地面，課本散落一地。
  2. 病房裡，小凱頭骨骨折、腦出血；王老師拿出監視器畫面（黑白畫面、紅圈標出推人的手）。接著是判決卡：判賠 12.4 萬元。
  3. 小天使擊退小惡魔、時光倒轉，你自己選擇怎麼回答。選對的話，兩人靠右慢慢走，轉角平安遇到抱著作業簿的小美，得到「走廊安全徽章」。
  4. 選「我不跑，你自己跑」或「用快走的」，小凱會在轉角撞倒小美、作業簿散一地，學到「轉角要放慢、也要勸朋友不要跑」。
- 第二關地點：**遊樂器材區**，案例是「溜滑梯逆向爬」，依真實新聞事件改編。故事走向如下：
  1. 你和小凱排隊等著爬攀爬網上溜滑梯，小宇已經在上面的平台。小凱說不信你手腳最快，小惡魔驅使你直接從滑道往上爬（第一人稱，手腳並用）。
  2. 小宇沒看到下面，坐下來就滑了下來，撞上你，你從滑道側邊摔落，右手骨折。王老師帶你到保健室，用固定板和三角巾包好。
  3. 隔天，遊戲場很安靜，沒有人敢玩溜滑梯。小天使擊退小惡魔、時光倒轉，你自己選擇怎麼回答。選對的話，排隊從攀爬網上去、從滑道坐著滑下來，得到「遊具安全徽章」。
  4. 選「插隊」的話，你和小凱在攀爬網上推擠，小凱摔下來，一樣遊戲結束。
  5. 模型只有攀爬網、沒有樓梯，所以規則寫成「從攀爬網上、從滑道下」。劇本裡選錯會回到選項，這裡沿用第一、三關的做法：選錯就悲劇重演、遊戲結束，可以再挑戰一次。
- 角色在劇情中走路會自動繞開柱子、牆壁與遊具（碰撞格＋路徑規劃），並在每個場景檢查腳有沒有陷進地板或穿進障礙物。
- 人與人不會重疊：站著、走路、跑步的角色靠得太近時，每一格會把他們往兩邊推開（第一人稱時只推別人）；測試時也會記錄任何兩人身體重疊的畫面。
- 掉落的書本用簡單的物理模擬：有重力，撞到人的頭、胸口、腰會彈開，撞到牆會反彈，落地後停住、平躺在地上，不會穿過任何人。
- 第二關：爬攀爬網時身體順著網子往前傾、面向平台手腳交替往上爬，到頂端跪上平台再站起來；滑梯相撞後會播放第三人稱的「慢動作重播」，看清楚小宇滑下來撞上往上爬的你、你從滑道側邊翻落。
- 攀爬網動作用「關節角度關鍵影格＋手腳反向運動（IK）」製作，並請 AI 以骨科醫師角色檢視兩輪後修正：爬網時對側手腳交替、一次只動一肢（三點接觸），手抓在肩膀寬度的橫桿上；到頂端時平台在胸口高度先雙手撐上平台 → 撐起、右腳踩最上面一格 → 左膝跪上平台 → 四肢著地 → 雙膝跪直 → 單膝跪 → 站起來，膝蓋和腳都完整放在平台上。正確結局排隊、爬網、滑下來的過程會收掉子畫面。
- 保健室改用平行光照明（不用點光源）；角色材質如果在某台裝置上無法顯示，會自動換成簡化的卡通材質，並在畫面左下角顯示一行提示。執行中發生的程式錯誤也會顯示在左下角，方便截圖回報。

## 語音

第三集的台詞還沒有配音，遊戲會先用裝置朗讀（TTS）代替。製作語音的步驟和第二集相同：

1. 手機安裝 App「語音工作室」，匯入 `voice-project/` 的專案檔。
2. 產生全部句子，匯出 `all.txt` 和 `map.txt`。
3. 套用到遊戲，兩種方式擇一：
   - 只在這支手機或平板上用：在遊戲開始畫面最下方按「🎙 匯入語音」，同時選 `all.txt` 和 `map.txt`。
   - 讓所有學生都用：在 repository 建立 `voice/` 資料夾，把 `all.txt`、`map.txt` 放進去。

每個角色固定一個音色，角色感用 App 的後製做出來；同一音色的角色用音高、共振峰、語速拉開（App 的音高最多拉高 1.6 倍，數值已在範圍內）。

- 產生後請在 App 裡逐句聽過，標「⚠ 多音字」的句子特別注意；不滿意的句子可以單句重錄。

## 注意事項

- **模型授權**：角色模型的 VRM 授權設定為「不允許再散布」。Public repository 裡的檔案任何人都能下載，請確認這符合你的意願。
- **學生進度**（徽章）只存在各自的瀏覽器裡，換裝置或清除瀏覽資料就會重來。存檔使用獨立的 key，不會和第二集的進度互相覆蓋。
- **修改台詞**時，`index.html` 和語音專案檔要改成一樣的文字，再重錄語音。
